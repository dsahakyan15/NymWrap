# Единственный владелец разблокированного хранилища

## Решение

`nymwrapd` владеет SQLCipher, настройками и состоянием Shield. Tauri и `nw-api`
передают типизированные команды по закрытому shadow IPC. Браузерный native host
использует отдельную схему cover IPC: только одобренные задания, пауза и снимки;
схема не позволяет запросить vault, историю, секреты или персону.

Каждый ответ связан с версией, полосой, случайным идентификатором и ожидаемым типом
команды. Повтор после ошибки запрещён: клиент не знает, успела ли команда изменить
состояние. Запросы и ответы ограничены 16 MiB, чувствительные буферы обнуляются.

На Windows и macOS клиент дополнительно сверяет образ серверного процесса с
установленным `nymwrapd`. На Linux используется проверка UID сокета: включённый
`PR_SET_DUMPABLE=0` закрывает чтение `/proc/<pid>/exe`; дополнительная защита от
процессов того же пользователя обеспечивается профилем песочницы, а не обещанием
проверки имени бинарника.

## Компромисс

Появляется обязательный фоновый процесс. UI запускает только соседний установленный
бинарник (в debug также путь сборки), очищает окружение и блокирует workspace при
закрытии. Прямой API требует предварительного разблокирования через UI или CLI.
Модель может работать отдельно и не получает доступа к ключам или файлам store.
