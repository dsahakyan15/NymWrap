# API-ключи провайдеров

## Решение

`nw-cred` использует уже закреплённые `keyring 3.6.3`, `rand 0.8.8`, `zeroize`
и `nw-platform`. Токены хранятся в отдельном сервисе хранилища ОС
`NymWrap.provider.v1` под случайным 256-битным идентификатором. Конфигурация может
содержать только ссылку. Подстановка plaintext-файла при недоступности ОС запрещена.

Токен проверяется на размер и печатные ASCII-символы без пробелов, CR/LF и иных
управляющих байтов. В памяти значение находится в `LockedString`, включая ключи
пула. Исключения и журналы не содержат ключей. Пул не возвращает использованные
ключи другому разговору.

OS-секрет не следует создавать до записи зашифрованного staging-идентификатора
в каталоге ядра. Сбой после создания должен оставлять достаточно сведений для
очистки. Удаление vault и всего пространства должно сначала удалить эти OS-записи.
Интеграция каталога обязана сохранять это правило.

## Ограничение

Даже отдельные ключи могут быть связаны платёжным аккаунтом провайдера. Этот
механизм даёт L3 и не удовлетворяет профилям Strict/Paranoid без zkAPI.
