# Сопоставимое представление фактов в linkcheck

Development pilot 5/384 с ADR 0065/0066 снова дал 0 remote. Нейтральный
арифметический public_control получил rank 1/65 до и после generalize:
user/best-decoy 0.687098/0.598805 и 0.696860/0.599980. Это наблюдение ложного
срабатывания, а не измерение анонимности. Обнаружена структурная асимметрия:
досье пользователя было JSON со служебными ключами, ID и флагами, а приманки —
короткой прозой с префиксом «fictional person». История тоже была JSON.

Векторизатор получает текст фактов с одинаковым разделителем строк. Для
пользователя сохраняются claim и фактические evidence подтверждённых traits, каждое
личное/Device значение, все titles/searches/prompt_samples импорта, domain/count,
activity hour/count и ненулевые счётчики records/skipped_files. Trait ID,
approval/local_only flags и имена полей хранения не являются биографическими
фактами и в embedding не попадают. Исключена также одна точная служебная строка
«Подтверждено пользователем вручную», которую сам Workspace добавляет каждому
ручному trait; остальные evidence сохраняются. Неподтверждённые/отклонённые traits остаются
исключёнными. Приманки используют тот же текстовый формат без маркера fiction;
их значения по-прежнему не зависят от пользователя. Полная история сохраняет
все тексты и метки ролей, без JSON envelope. Vault и последнее leakcheck не меняются.

Пустая сводка без фактов не создаёт мнимое досье. Байтовые пределы, перекрытие
фрагментов и максимум по человеку из ADR 0061 сохраняются: факты не усекутся
ради успешной отправки. Временные копии проекции zeroize, на диске только прежние
зашифрованные источники. Никакие тексты не добавляются в журнал.

Регрессия production Workspace сначала воспроизвела передачу служебного
confirmed_persona в embedding. Она проверяет отсутствие метаданных и сохранение
каждого источника, evidence и импортных счётчиков после encrypted reopen.
Отдельно проверяется полная история с ролями. Удаление асимметрии само по себе
не доказывает причинность ложного срабатывания, качество nomic v1.5 в RU/HY или
репрезентативность приманок. Нужны новые реальные development измерения;
прежний pilot, неоткалиброванные пороги и all-L0 не дают приёмку. Held-out не создан.
