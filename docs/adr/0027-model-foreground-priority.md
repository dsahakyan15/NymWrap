# Приоритет вопросов человека над предварительной генерацией

## Решение

UnixModel помечает работу внутренним фиксированным заголовком foreground либо
background. Только подготовка приманок использует background; планирование,
диалог, классификация и embeddings человека сохраняют обычный режим.
nw-llmd отвергает неизвестное/дублированное значение. Этот заголовок не входит
в исходящий запрос провайдеру и не меняет границу leakcheck.

Background получает разрешение на inference только немедленно; при занятом
worker или ожидающем человеке возвращается model_busy и подготовка уступает.
Foreground имеет ограниченную очередь из восьми ожиданий, не более 110 секунд
на получение разрешения. Уже начатый нативный inference не прерывается: код
не пытается небезопасно остановить C++-поток. Приватный клиент ждёт до 240 секунд,
покрывая ожидание и ограниченную генерацию; автоматического повторного запроса
нет. После отказа фоновой подготовки действует прежняя пауза 30 секунд.

## Проверки

Контролируемый blocking backend через HTTP подтверждает: активная работа
завершается, новая фоновая задача сразу отклоняется, вопрос человека дожидается
разрешения и получает ответ, неизвестный режим отвергается. Новых зависимостей нет.
