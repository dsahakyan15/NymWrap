# Парсеры экспортов без открытых временных файлов

ZIP разбирается `zip = 9.8.1` с единственным декодером deflate-flate2-zlib-rs,
HTML — `scraper = 0.29.0` без CLI и загрузки ресурсов. Регулярные выражения не
подходят для вложенного HTML; ручной ZIP-парсер увеличил бы поверхность ошибок.
Оба парсера ограничены входом, количеством элементов и распакованным размером.
SQLite читается через безопасный deserialize_read_exact rusqlite в read-only
in-memory базе с trusted_schema=OFF, query_only и лимитом VM-инструкций.
WAL-образы отвергаются: отдельный файл без журнала не доказывает полноту снимка.
Версии и хеши закреплены в Cargo.lock; обычный SQLite используется только в памяти
для чтения чужого экспорта, пользовательское хранилище остаётся SQLCipher.

zip 9 требует zeroize 1.9; существующая зависимость обновлена до закреплённой
1.9.2. Base64 0.22.1 (уже используемый Shield) передаёт бинарный экспорт через
Tauri без преобразования байтов SQLite или ZIP в строку UTF-8.
