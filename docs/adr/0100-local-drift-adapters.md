# ADR 0100: видео и ИИ Drift только на локальных HTTPS-фикстурах

Статус: принято. Дата: 2026-11-26.

## Контекст

Задача 13 проверяет M5 без настоящих сервисов, профилей и аккаунтов. Существующий
исполнитель умеет искать Google/YouTube; видео и три разных редактора ИИ нужно
проверить отдельно. Успех синтетического DOM не доказывает совместимость живого.

## Решение

Добавить отдельный `LocalExecutor` с единственным разрешённым адресом
`https://127.0.0.1[:port]/drift-fixtures/{youtube|chatgpt|claude|gemini}/`.
Разрешение браузера на loopback — optional, запрашивается по кнопке. Существующий
поисковый исполнитель не получает маршрутов к настоящим ИИ-сервисам.

Сохраняются существующие cover-only `DriftTask` и команды `begin_search`,
`validate_search`, `finish_search`: названия исторические, контракт — одноразовое
исполнение ровно одобренного действия. Ядро повторно проверяет план, день,
сервис, финальный leakcheck и конфигурацию. Для ИИ требуется уже предусмотренный
`allow_ai_web_automation`, по умолчанию false; UI явно предупреждает о риске
нарушения условий сервиса и блокировки аккаунта. Это согласие разрешает только
локальную проверку новых адаптеров. `assisted` остаётся значением по умолчанию.

Фиксированный код работает в isolated world. Ввод — значения и текстовые узлы,
никакого выполнения строк страницы/модели. Для видео извлекается только bounded
идентификатор из фиксированной карточки; URL строится заново и остаётся в том же
loopback origin. Успех требует движущихся часов media, нормальной скорости,
видимой страницы и 20–90 секунд наблюдения; после завершения/остановки media
ставится на паузу; при потере scripting-доступа закрывается только созданная
исполнителем видеовкладка. ИИ отправляет один раз и проверяет точный текст одного
пользовательского сообщения; ответы и инструкции страницы не исполняются.

CAPTCHA, в том числе поздняя, вход без пароля, неизвестный DOM, потерянный ответ,
отзыв согласия/разрешения и пауза прекращают попытку. Повтор неоднозначной попытки
не разрешается. В safety stop уходят только случайный id и причина.

## Последствия

Новых зависимостей нет. Тестовые профили Chromium/Firefox одноразовые, фикстуры
оригинальные и без брендинга/чужих материалов. Браузерные тесты блокируют внешние
маршруты. Подмен отпечатка, обходов CAPTCHA и входа нет. Живые видео/ИИ выполняются
вручную; владелец отдельно заполняет ACCOUNT_ADAPTER_CHECKLIST. Работа с настоящими
аккаунтами и включение живых адаптеров в эту задачу не входят.
