# Одноразовая инвентаризация секретов устройства

## Решение

`nw-probe` — отдельный доверенный shadow-процесс без доступа к модели, vault и
сервисным IPC. Core передаёт только ограниченный набор переменных идентичности,
которые очищаются sandbox launcher, и открытый только для чтения handle глобального
gitconfig. Сам worker читает системные идентификаторы. На Windows — AppContainer без
сетевых, location и wiFiControl capabilities; на Linux — отдельный профиль bwrap,
без домашнего каталога и сервисных сокетов. До чтения входа worker устанавливает
seccomp, запрещающий IP/packet sockets. NETLINK_ROUTE нужен только для чтения
локальных интерфейсов; capabilities сброшены, изменение интерфейсов запрещено ОС.
Сеть хоста видна этому доверенному probe как список интерфейсов; агентам этот
профиль недоступен. Профиль агентов по-прежнему имеет отдельный network namespace.

Ответ — единственный строго типизированный кадр с лимитом 128 KiB и EOF.
Данные и буферы IPC zeroize; на диск результат попадает только в зашифрованный
домен Vault. Worker не выводит значения в stderr. Идентификаторы не передаются
в cover IPC. Linux использует memfd для публичных заглушек и наследуемые read-only
дескрипторы gitconfig: временных файлов с содержимым нет.

Источники, к которым ОС отказала в доступе, отмечаются unavailable, а не «проверено».
Запрещено добавлять capabilities Wi-Fi или геолокации ради успешного отчёта.
Неполный результат показывается пользователю; для пропущенных значений доступен
ручной список секретов. При включённом сборе удалённая отправка требует успешного,
полного результата моложе суток. Ручное добавление не подменяет проверку источника.
macOS-источники без реализованного системного адаптера
также возвращают unavailable. Неполные проверки не закрывают M3H.

Обновление при открытии пространства и не чаще раза в сутки; ручной запуск
разрешён из UI. Старые значения сохраняются для защиты скопированных ранее
фрагментов. Удалённые человеком Device-секреты не возвращаются при следующем
сборе: их хеши подавления хранятся внутри зашифрованного Vault. Изменение списка
инвалидирует ожидающие разрешения на отправку так же, как изменение личных секретов.

Новые зависимости — только локальный crate nw-probe, с точной версией 0.1.0;
внешние пакеты уже закреплены workspace. Дополнительные features windows-sys
0.61.2 включают только read-only API инвентаризации. WLAN-профили запрашиваются
без WLAN_PROFILE_GET_PLAINTEXT_KEY; из XML извлекается только SSID hex, включения
gitconfig не выполняются и приводят к явному incomplete-результату.

## Проверка Windows

Первоначальный LPAC запускался, но ОС отказывала в user/host/MAC/IP/Wi-Fi/MachineGuid.
Для доверенного probe применяется обычный AppContainer, без
ALL_APPLICATION_PACKAGES_OPT_OUT. У модели и импортера остаётся LPAC. Все
capabilities по-прежнему отсутствуют; ACL временного профиля ограничены чтением.
Отдельный настоящий отрицательный тест подтвердил запрет чтения/записи приватных
файлов, TEMP, дочерних процессов и отсутствие доставки TCP/UDP для обоих профилей.
В настоящем probe доступны host/MAC/IP/MachineGuid; user display и Wi-Fi на этой
машине остаются unavailable. Дополнительные capabilities для обхода отказа не
выдаются. Этот результат не закрывает полноту M3H.
