# Linux-проверки из Windows без WSL и администратора

Для реальной проверки ядра Linux используется отдельная временная QEMU TCG
машина с Alpine, без установки служб, драйверов, Hyper-V или изменения Windows.
Это dev-инструменты, не зависимости поставляемой программы. ISO подключён только
на чтение, гостевая система работает в RAM, каталог пользователя и workspace не
монтируются. В гостя передаются только синтетические тесты. Сеть гостя разрешена
для подготовки пакетов; тесты отдельно проверяют запрет сети внутри песочницы.
Это не production MicroVM launcher и не проверка защищённости гипервизора.

Средства закреплены по версии и опубликованному хешу, извлекаются только в target:

  `5bcf9eed634e8575a37b74f445af41a2fe4106da512d0c30c368301d4c105037fdfab40a5287367a28a957624cddebbc8c07e16c88ab6634f554cdf3d16bf543`.
- Alpine virt 3.24.4 x86_64 ISO: SHA-256
  `157d353f8e54252cad2d9812a0d56bb7fa2231fc154a110e1d180d7480ef8b4f`.
- 7-Zip 26.06 x64 installer payload: SHA-256
  `9b697f65ecc2d9b0152f5ee96d72dde522a7827690349d9307935dacf40f42ec`;
  bootstrap 7zr.exe 26.06: SHA-256
  `e80db2dad715a6c5adabe292d31ed54e11f4e9b99ca349827b50573b175891bc`.

Источники: [QEMU Windows downloads](https://www.qemu.org/download/#windows),
[публикация SHA-512](https://qemu.weilnetz.de/w64/qemu-w64-setup-20260811.sha512),
[Alpine downloads](https://alpinelinux.org/downloads/),
[официальный 7-Zip release](https://github.com/ip7z/7zip/releases/tag/26.06).
Установщики не запускаются: используются только извлечённые файлы. Пакеты в госте
проверяются штатными подписанными Alpine indexes. Rust тесты собираются по lock
для x86_64-unknown-linux-musl с rust-lld; это также проверяет переносимость FFI.

Команда `node scripts/linux-isolation-probe.mjs --prepare` выполняет подготовку,
сборку и прогон. Позже --prepare можно опустить. Для гостя закреплены
python3=3.14.10-r1 и bubblewrap=0.12.0-r0; зависимости проверяются apk.
Тесты выполняет UID 1000. До фильтра TCP/UDP доступны; после установки seccomp
они запрещены и в существующем, и в новом потоке, а Unix IPC работает. Bwrap
даёт агенту только рабочий каталог и API socket; файл вне него и core socket
недоступны. Хостом этой bwrap-проверки является Linux-гость, не Windows.

Отчёт включает ядро, UID, source/lock/test binary hashes; serial log содержит
только синтетический прогон. Успех фиксируется после проверки всех маркеров и
неизменности исходников. Ошибка, таймаут или потеря VM завершают команду отказом.
QEMU и сервер останавливаются; временные распакованные инструменты удаляются
после проверки абсолютного пути. ISO и проверенные download archives кэшируются.
Отдельный Windows CI job повторяет прогон и сохраняет отчёт.
