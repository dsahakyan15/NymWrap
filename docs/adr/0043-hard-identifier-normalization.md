# Жёсткие данные устройства и окружения

Shield закрывал PII в тексте (email, телефоны, IPv4/IPv6, имена, личные секреты),
а `nw-netd` уже строит HTTP-запрос с нуля по allowlist заголовков и выходит
только через Tor. Не были описаны признаки устройства и окружения: Wi-Fi и MAC,
GPS и геолокация, часовой пояс в тексте и в ритме, имя компьютера и
пользователя, пути, идентификаторы железа, git-личность, окружение агента в
песочнице, отпечаток TLS, метаданные вложений, оператор локальной сети.

Решение: каждый жёсткий признак закрывается на самом раннем слое, где он
появляется (сеть, протокол, окружение, время), а Shield страхует на уровне
текста. Признак либо отсутствует, либо заменён значением, общим для всех установок
(`UTC`, `localhost`, `user`, `/work`, общий machine-id). Случайное значение на
установку отвергнуто: оно само становится устойчивым идентификатором.

Состав (SPEC §4.9):

- `nw-probe`: одноразовый процесс без сети собирает секреты устройства (имя
  пользователя и ПК, домашние пути во всех формах, MAC, сохранённые SSID, локальные
  IP, machine-id, часовой пояс, git-личность) и передаёт их в vault как
  `SecretKind::Device`. Пользователь видит и правит список.
- Детекторы `minimize`: GEO, MAC, IMEI, USER_PATH, TZ, DATETIME, GUID.
- Нормализация окружения песочницы агентов: hostname, пользователь, HOME, TZ,
  локаль, machine-id, без `/sys`, D-Bus, GeoClue, NetworkManager и настоящего
  `.gitconfig`. На Windows агенты strict/paranoid работают через WSL2;
  AppContainer без capabilities геолокации и Wi-Fi.
- Протокол: закреплённые allowlist заголовков и полей тела, один ClientHello для
  всех ОС, golden-тест отпечатка.
- Время: отложенная отправка async-заданий, размытые границы сеанса, честное
  предупреждение о ритме под L3.
- Сеть: опциональные мосты (obfs4, snowflake, webtunnel) против оператора сети.
- Вложения отвергаются, пока нет локального очистителя метаданных.
- Проверка гигиены ОС только читает настройки и даёт инструкции. NymWrap не
  меняет MAC, имя компьютера и сетевые службы сам: это требует прав
  администратора и выходит за границу процесса.
- Полоса легенды не подделывает IP и местоположение (инвариант 7); вместо этого
  постепенно сдвигается окно активности легенды.

Отвергнуто: подмена геолокации и часового пояса в полосе легенды (делает аккаунт
подозрительным, противоречит честной автоматизации); случайные идентификаторы
на установку; автоматическое изменение настроек ОС.

Новые зависимости: мосты требуют `tor-ptmgr` из arti и внешних бинарников
pluggable transports; их закрепление оформляется отдельным ADR при реализации.
Остальное реализуется без новых зависимостей.

Остаточные риски записаны в THREAT_MODEL §8: guard или мост видит IP, провайдер
интернета видит время работы машины, отпечаток TLS выделяет пользователей NymWrap
как группу, ядро и процессор видны агенту, детекторы понимают формат, а не смысл.
