# Атакующая модель выделяет факты, код ранжирует досье

Локальный pilot дал 0 remote / 8 разговоров; прежний 7B forced-choice атакующий
угадал только два nonce-случая. На Ubuntu тот же атакующий исчерпал 110 с.
Это не калибровка связывания: нельзя замораживать такой benchmark или объявлять
защиту эффективной по ошибкам слабого атакующего.

Вместо символьного поиска ID среди 64 строк модель получает полный словарь
фактов всех кандидатов и накопленный наблюдаемый разговор. Она возвращает
только множество букв обнаруженных фактов/парафразов. Фиксированная грамматика
LinkageFactsV1 ограничивает формат и число элементов 26; код отвергает дубли,
несуществующие буквы и дополнительные поля без случайной подмены ошибки.

Соответствие фактов 64 людям остаётся у кода. Он ранжирует досье по числу
наблюдаемых фактов; точное совпадение известного private/Device nonce имеет
приоритет. Стабильная публичная перестановка разрешает равенства, включая
пустое множество доказательств. Функция ранжирования не получает индекс
субъекта или правильный ответ. Только после выбора ID оценщик сравнивает его
с меткой. Независимый literal attacker сохраняется. Это модельный экстрактор
с детерминированным ранжированием, а не end-to-end угадывание ID одной LLM.

Для двух внутренних linkage-грамматик CPU deadline увеличен до 200 с в пределах
прежнего outer timeout 240 с. PrivacyV1, ответы и embeddings сохраняют 110 с;
пользовательский HTTP API не получает произвольный параметр таймаута. Медленная
загрузка worker или неуспевшая атака по-прежнему дают failed/unmeasured.

Изменение протокола требует нового полного development-прогона и калибровки
каждой пары язык/приватная группа, затем freeze и новый blind held-out.
Текущие примеры используют точные шаблоны: успех на них не доказывает качество
семантического связывания произвольных парафразов или реальных биографий.
Тесты проверяют выбор по совокупности фактов без subject, nonce-приоритет,
равенства и отказ на неверном выводе; native/private-IPC проверка грамматики
не считается измерением точности атаки. CI временно заблокирован биллингом.

В синтетический evaluator добавлены агрегаты настоящих linkcheck inspections:
число людей, ранг, квантованные user/best-decoy/background scores и решение. Observer не
получает текст, векторы или стабильные хеши, не изменяет возвращённый Rank и по
умолчанию отсутствует. Это данные экспериментального отчёта, не телеметрия
реального пространства. Remote-наблюдение без linkcheck агрегатов отвергается
сборщиком отчёта. Эти показатели нужны для разбора all-L0 и ложных срабатываний.
