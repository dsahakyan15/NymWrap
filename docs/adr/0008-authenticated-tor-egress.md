# Отдельная сборка Tor и проверяемое шифрование его состояния

## Решение

`daemons/nw-netd` — отдельный Cargo workspace. `arti-client =0.48.0` использует
`rusqlite <0.41`, а хранилище — SQLCipher через `rusqlite =0.43.0`; разделение
процессов исключает конфликт нативных `links=sqlite3` без ослабления хранилища.
Его зависимости закреплены в отдельном Cargo.lock.

Общие DTO обновляют закрепления до `serde =1.0.229` и `serde_json =1.0.154`,
минимумов Arti 0.48.0. Тестовая зависимость сетевого workspace —
`tempfile =3.27.0`; основному workspace это обновление не требуется.

На разговор создаётся `TorClient::isolated_client`. DNS имён провайдеров выполняет
Tor. HTTPS поверх потока Arti: `tor-rtcompat =0.48.0`, `tokio-util =0.7.20`,
`tokio-rustls =0.26.6`, `rustls =0.23.46`, `webpki-roots =1.0.12`.
Проверка сертификатов обязательна; TLS resumption и early data выключены.
Нет прямого TCP-коннектора, редиректов, системных прокси и повторов запроса.

Core передаёт случайный ключ XChaCha20-Poly1305 через stdin дочернего процесса.
Ключ живёт в mlock, стирается при завершении; ни argv, ни диск его не содержат.
Кадр аутентифицирует версию shadow-протокола и монотонный номер; подмена и повтор
отвергаются. EOF родительской трубы отменяет сетевую работу. Это дополнительная
граница авторизации поверх ACL, а не замена песочнице.

JSON дополняется пробелами после значения до корзины байтов. Это валидный JSON
без неподдерживаемого провайдером поля `padding`; заголовок Content-Length
соответствует корзине. Корзины токенов требуют закреплённого токенизатора.

## Хранение и ограничения

До bootstrap проверяется шифрование каталога: Windows EFS или Linux fscrypt
(`FS_IOC_GET_ENCRYPTION_POLICY_EX`). EFS включается только на пустом каталоге,
после чего статус перепроверяется. Неподдерживаемая система завершает запуск.
Файлы Tor не заменяются незашифрованной временной директорией. Состояние guard
сохраняется, а не создаётся заново при каждом запуске.

Эта реализация не означает закрытие M2: отдельно необходимы испытания изоляции
процессов, остановки транспорта и захвата трафика. Платёжные API-ключи дают L3;
Tor сам по себе не делает их анонимными.
