# Проверка штатного Firefox и публичного DOM

Кроме Chromium используется штатный Mozilla Firefox 160.0.1 x64, без установки
в систему или доступа к профилю пользователя. Закреплённый SHA-512 установщика:
`e0356669960e73528d53c194ae2e3f46d663483073da16d58ba318cd67036d4023a10a23f47e1b733554dce88d8b7c299d806e06bbe31c590286ded20886eaea`
из [Mozilla SHA512SUMS](https://archive.mozilla.org/pub/firefox/releases/160.0.1/SHA512SUMS).
Извлечение выполняет закреплённый 7zr 26.06 из ADR 0039. Хеш дерева проверяется
при повторной установке test tool. Это dev-инструменты, производственных зависимостей нет.

Управление — небольшой последовательный клиент документированного
[Marionette protocol](https://firefox-source-docs.mozilla.org/remote/marionette/Protocol.html),
только loopback. Для временной extension UI включается system access только
в дочернем тестовом Firefox. Новый одноразовый профиль, telemetry/update выключены;
маскировки webdriver/отпечатка нет. JavaScript продукта и CSP сохранены; native
host на фикстурах заменён общим синтетическим обработчиком в тестовой копии.
HTTPS-прокси допускает только фиксированные локальные fixture origins. В CI эта
проверка выполняется на Windows; другие ОС не объявляются проверенными.

Живые публичные интерфейсы проверяются отдельно, без аккаунтов, поиска, ввода
личных данных, кликов по видео и обхода CAPTCHA. Сохраняются origin/path, состояния
и количества, без текста страниц. Это проверка совместимости DOM, не анонимности
браузера или персонализированной ленты. Реальные аккаунты не используются.

Проверка выявила гонку Firefox: tabs.get может вернуть complete для начального
about:blank раньше целевой страницы. До чтения DOM executor ждёт целевой URL;
потерянная попытка ввода не повторяется. Это сохраняет one-shot permit.

Публичный MyAdCenter перенаправляет на adssettings.google.com/anonymous.
Прежний data-nymwrap-ad-topic не подтверждён реальным интерфейсом и удалён:
расширение снимает только YouTube, рекламные темы добавляются в Mirror вручную.
Загрузка анонимной страницы ИИ-сервиса не объявляется проверкой его адаптера,
авторизации или автоматической отправки. Проверка останавливается при challenge.

Дополнительная явная Windows-проверка соединяет штатный Firefox с настоящими
release nw-drift-host/core. Используется уникальное временное имя host в HKCU,
отдельный профиль и пустое синтетическое зашифрованное пространство. Небольшой
скомпилированный Rust relay задаёт только тестовые каталоги и передаёт stdio
настоящему host без изменения пакетов. Shim в тестовом popup меняет только имя
host; JS продукта и CSP сверяются. Пауза/возобновление подтверждаются независимым
вызовом к ядру, сетевой резерв нулевой. Сохраняются хеши компонентов/relay/теста.
После теста удаляются временный ключ HKCU и созданные пустые родительские ключи,
профиль, пространство и OS-ключи. Основная регистрация не перезаписывается.
Эта проверка вызывается отдельно и требует свободного daemon endpoint.
В CI она добавлена в Windows desktop job после release-сборки; чтение публичных
сервисов остаётся явной ручной командой и не становится сетевым gate CI.
