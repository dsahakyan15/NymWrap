# Отдельный протокол native messaging для легенды

Native host зависит только от типизированного протокола легенды, локального IPC
и функций ОС; он не связывается с nw-core, nw-vault или nw-shield. Общий generic
RPC отвергнут: даже ошибка выбора метода не должна открывать расширению реальную
историю или персону. Снимки передаются внутрь ядра, ответ содержит только Ack;
позиции относительно реальной персоны возвращаются только пользовательскому UI.
Выполнение привязано к плану, этапу, дню и полному тексту одобренного задания,
чтобы старая кнопка не могла подтвердить действие нового дня.
