# Идентичность embedding-преобразования и кеша

Native Qwen-кандидат ADR 0068 прошёл локальные проверки трёх тем EN/RU/HY:
CPU/private IPC и настоящий Windows LPAC. Это позволяет подготовить явный
development opt-in; default linkcheck остаётся Nomic с прежними порогами.
Калибровка Qwen и held-out не выполнены. Одного SHA файла недостаточно:
старая версия worker могла применить к этому файлу mean вместо last.

Каждый identified embedding теперь содержит recipe_id вместе с SHA.
Recipe связывает pooling, префикс, размерность, нормализацию и предел окна.
Значения зафиксированы в nw-llm::embedding; native Cpu выбирает их по
проверенному хешу. Windows worker возвращает SHA/recipe в обязательном
типизированном stdio ответе, broker проверяет оба до HTTP-ответа. Старая
схема без recipe не разрешает identified/linkcheck; обычный embed остаётся
совместимым. Метаданные не являются аттестацией чужого процесса: прежняя
проверка kernel peer/owned Child выполняется до передачи досье.

Core принимает только две известные пары SHA/recipe, проверяет точную
размерность и конечные векторы. Кеш references хранит пару; изменение
настройки не переиспользует старое векторное пространство. Нужен новый Engine,
который production уже создаёт после изменения конфигурации. Ошибка пары,
неизвестный hash или неправильная размерность сохраняют L0.

Регрессии проверяют отсутствие recipe при верном SHA, подмену mean/last,
ошибку после заполнения кеша, замену модели и неверную размерность. Native
проверки обязаны пройти повторно с новым протоколом. Во время первого общего
native CPU прогона две тестовые инициализации process-wide llama.cpp
конфликтовали; это не был успешный прогон. Общий test-only mutex устранил
конфликт, оба native CPU теста прошли вместе за 8,48 с. Production остаётся
одним Cpu на процесс. Полный CI по-прежнему заблокирован биллингом.

Повтор с новым протоколом завершён локально: оба CPU теста 17,02 с, оба Windows
LPAC теста 23,14 с. Проверка Qwen включает одинаковый вектор при другой длине
самого длинного текста в партии. Отдельный `--sample dev_0002` всегда создаёт
diagnostic, который полный validator/merger отвергает; выбор embedding и catalog
SHA/recipe/dimension входят в provenance. Default и пороги этим не меняются.
