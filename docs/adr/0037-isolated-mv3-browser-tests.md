# Изолированные MV3 browser tests

Для проверки реального MV3 runtime и scripting.executeScript добавлен только
devDependency `playwright =1.65.1`, с integrity-хешами npm lock. Обычные unit tests
не требуют браузера; отдельная команда использует поддерживаемый Playwright
Chromium и новый временный профиль под target. Синтетические страницы отдаёт
HTTPS-сервер только на loopback и случайном порту; фиксированные имена сайтов
сопоставлены с ним только флагом этого браузера, остальные DNS-запросы отвергаются.
Сертификат и ключ создаются PowerShell 7 в памяти без записи в key store или файл.
Только временный профиль принимает этот сертификат. Native messaging заменён
тестовым обработчиком. Такой сервер проверяет и начальную навигацию вкладки из
service worker, которую перехват Playwright route может пропустить.
Продуктовые scripts/CSP не меняются; отдельный manifest тестовой копии заранее
даёт только фиксированные host permissions для fixture-origin. Профиль пользователя,
регистрация native host и реальные аккаунты не используются. Это проверка
Chromium/DOM/MV3 на фикстурах, а не подтверждение актуальных интерфейсов сервисов.
Подход выбран потому, что эмуляция DOM не проверяет межпроцессную работу MV3;
системные Chrome/Edge убрали нужные sideload-флаги, поэтому они не используются
([официальная документация Playwright](https://playwright.dev/docs/chrome-extensions)).
