# Единственный HTTP socket внутри Linux-песочницы агента

## Решение

nymwrap run передаёт bwrap только файл приватного shadow HTTP socket как
/run/nymwrap/api.sock. Проверяются тип socket, абсолютный путь, имя api.sock,
UID и отсутствие прав группы/остальных; symlink не принимается. Core RPC,
полоса легенды, модель, домашний каталог и runtime directory не монтируются.
Проект остаётся единственным каталогом host на запись; системные библиотеки
доступны только для чтения. Как прежде, сеть и PID namespace отдельные,
capabilities сброшены, seccomp CLI наследуется агентом.

NYMWRAP_API_SOCKET задаёт путь внутри песочницы. OPENAI_BASE_URL — обычное
http://localhost/v1 для клиентов с явно настроенным Unix transport. Локальный
TCP listener не создаётся: стандартный SDK без UDS transport не может связаться
с API, а прямой HTTP не становится обходным выходом. API запускается человеком
до команды run. Без приватного socket или bwrap запуск прекращается.

## Проверки и границы

Linux-тест с настоящим bwrap проверяет доступ к единственному socket, отсутствие
host fixture/Core IPC, отказ TCP/UDP IPv4/IPv6 и запись только результата в
проект. Он запускается отдельно в Linux CI. На Windows тест не исполняется;
нативный run остаётся недоступен. MicroVM и прозрачный TCP adapter для SDK ещё
не добавлены. В nw-sandbox использованы уже закреплённые nw-platform и tempfile;
новых внешних пакетов нет.
