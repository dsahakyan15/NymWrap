# Коды отказа локального worker без содержимого

Development pilot сообщал local_model_unavailable как для недоступности,
так и для отказа вычисления. Windows worker отбрасывал причину в Failed {},
сервер объединял ошибки в HTTP 503, клиент терял различие. Регрессия в
tests/leak сначала получила 503 вместо ожидаемого 504.

Одноразовый worker передаёт закрытый enum причины. Текста ошибки native
библиотеки, пути модели, фрагмента запроса и дополнительных полей в схеме нет.
Broker сохраняет Timeout/TooLarge; приватный HTTP отображает их в 504/413,
UnixModel — в ModelError::Timeout/TooLarge. Остальные отказы имеют общий код.
Лимиты вычисления и обмена остаются 110/240 секунд, автоматических retry нет.
Старый/неизвестный формат ответа отвергается. Broker запускает копию того же
бинарника, поэтому смешивание версий worker не требуется.

Канареечная регрессия проверяет оба метода, точные коды и отсутствие содержимого
в HTTP/IPC. Отдельно проверяются неизвестная причина и попытка добавить message
в кадр worker. Настоящий Windows LPAC прогон прошёл за 84,87 с: ограниченная
грамматика выбора и TooLarge при переполнении контекста сохранились до клиента.
Локальное доказательство не заменяет межплатформенный CI.
