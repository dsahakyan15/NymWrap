# Заморозка и статистика проверки связывания

Development и held-out имеют независимые синтетические профили и случайность.
Held-out создаётся только после заморозки кода, модели, настроек и завершённой
development-оценки. Изменение защиты после просмотра результата превращает этот
held-out в регрессию; для новой приёмки нужна новая невиденная часть.

Кандидат пользователя выбирается равномерно среди N досье, порядок случайный;
один эксперимент — один разговор с полной накопленной историей. Отдельные языки
и публичные контрольные задачи показываются отдельно. Полезность требует
проверки настоящего ответа по заранее заданному критерию; сохранение слов
в переписанном вопросе не считается полезным ответом. L0, ошибки и непроведённые
проверки не исчезают из знаменателя полезности.

Публикуются k/n, точный двусторонний интервал Clopper–Pearson 95% и односторонний
binomial P(X≥k | p=1/N). Значимое превышение при α=0.05 — провал, отсутствие
значимости не доказывает равенство вероятностей. До принятия результатов нужны
полные пары raw/outbound и подтверждение, что атакующий распознаёт исходные
приватные вопросы лучше случайного. Ошибка ответа атакующего и отсутствие
исходящих данных дают неизвестный результат. Публичные задачи не разбавляют
частную выборку: её top-1 проверяется отдельно. Интервалы описывают выбранный
синтетический генератор, не вероятность анонимности реального человека.

Формулы: [NIST §7.2.4.1](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm),
[SciPy binomtest](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binomtest.html).
Собственная реализация без новой зависимости проверяется на опубликованных
численных примерах и граничных значениях. Пока есть только статистический модуль:
freeze-проверка и полный evaluator остаются открытыми. Подготовлены 384
development-примера (EN 127 / RU 124 / HY 133), с 64 новыми синтетическими
досье на разговор, раздельными и накопленными фактами, Device/личными канарейками,
инъекциями и публичными задачами. Полезность этого генератора ограничена целой
арифметикой. Held-out ещё не создан; генератор CLI не принимает такой режим.
