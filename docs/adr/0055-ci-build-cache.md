# Кеш зависимостей и промежуточной сборки CI

Холодная Windows desktop-сборка занимает больше 40 минут. Для checks добавлен
actions/cache v6.1.0, закреплённый на commit
55cc8345863c7cc4c66a329aec7e433d2d1c52a9. Ключи раздельны для job/ОС/архитектуры
и содержат toolchain, manifest/lock, rustflags и bootstrap-скрипты. Нет общего
restore-prefix и межплатформенного восстановления. Все шаги проверок выполняются
после восстановления кеша; cache-hit не является доказательством проверки.

В кеше только Cargo registry/git, промежуточные build/deps/fingerprint и
закреплённые Perl/libclang. Пространства, профили браузеров, ключи ОС, учётные
данные Cargo и результаты сеансов туда не включены. Fuzz и будущие независимые
сборки воспроизводимости используют отдельные чистые jobs без этого кеша.

Основание: [официальные inputs/runtime и scope кеша](https://github.com/actions/cache/tree/55cc8345863c7cc4c66a329aec7e433d2d1c52a9).
Кеш работает на Node 24. Его сохранение/восстановление ещё требует реального CI;
оно не закрывает ни один критерий SPEC.
