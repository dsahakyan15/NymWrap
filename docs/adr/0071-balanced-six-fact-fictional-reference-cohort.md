# Сопоставимые вымышленные досье из шести фактов

В development после ADR 0069 public_control dev_0006 получил rank 1/65 до и
после generalize, хотя в исходном вопросе нет фактов субъекта. Это ложный
отказ на контрольном случае, не доказанная утечка. Три факта прежних приманок
охватывали craft/interest/schedule; у subject было шесть фактов, включая school,
tool и project. Обобщённое «school» могло оставаться свойством только досье
пользователя. Удаление JSON envelope не устранило эту асимметрию содержания.

Публичный фиксированный cohort теперь содержит 64 разных вымышленных человека
с шестью осями: craft, interest, schedule, school context, tool, project. У каждой
оси четыре значения по 16 вхождений; любая пара значений разных осей встречается
четыре раза. Первые три оси задают уникальный полный декартов набор, остальные
детерминированы публичной конструкцией. Данные пользователя, его язык, устройство,
импорт и ответы моделей не участвуют в создании приманок. Разметка и лимиты
текста одинаковы, кандидатов по-прежнему 65 вместе с пользователем.

Это структурная поправка к искусственному prior, а не новая калибровка порогов
или оценка реальной популяции. Шесть фактов не представляют любое настоящее
досье; алгебраическая конструкция задаёт искусственные зависимости. Новый cohort
может изменить и ложные отказы, и пропуски, поэтому прежние числа не переносятся.
Пороги/default embedding не изменены. Нужны новый полный development, freeze,
слепой held-out и измерение обоих атакующих. Никакой выигрыш в приватности пока
не заявлен. Уже запущенный первый shard использует сохранённый прежний бинарник
d435c6e; его provenance не меняется от редактирования исходников.

Регрессия сначала подтвердила прежние три факта. Затем проверяет шесть осей,
покрытие отдельных признаков и их пар, 64 разных документа и полную независимость приманок
от двух разных private user inputs. Тест геометрии не подменяет настоящую
модельную проверку public_control или статистическую приёмку.
