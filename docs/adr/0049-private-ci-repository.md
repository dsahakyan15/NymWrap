# Приватный репозиторий для проверяемого CI

Пользователь требует фактические зелёные GitHub Actions, включая проверки на
других ОС. Рабочий каталог не имел .git, метаданные T3 не содержали repository
identity, а соответствующий репозиторий не найден в подключённом аккаунте.
Поэтому исходное дерево оформляется начальным commit в приватном NymWrap этого
аккаунта. Создание и запуск CI входят в прямо запрошенную работу; публичный
релиз, приглашения и настоящие аккаунты сервисов не создаются.

Модели, target, node_modules, сборки, логи и локальные данные не добавляются.
Перед первым push проверен индекс: предварительная проверка не нашла больших
файлов или ключей реальных сервисов. Единственное совпадение PRIVATE KEY —
строковая PEM-метка в коде создания синтетического HTTPS-сертификата браузерных
тестов; самого ключа в исходнике нет. Текст фиксируется с LF для одинакового
checkout на ОС; бинарные ресурсы сохраняются без преобразования.
web3lesson остаётся отдельным публичным
подмодулем, закреплённым на a5cbfdf5c57c06fc15e8842bfacabf9be624a6c3;
его существующие локальные файлы и история не изменяются.

Локальный зелёный пакет и добавленный workflow не закрывают этап. Доказательство
CI — успешный run с конкретным commit, а не наличие репозитория или push.
Незакрытые критерии, held-out privacy, 24 часа fuzz и подпись остаются открытыми
независимо от результата базового workflow.
