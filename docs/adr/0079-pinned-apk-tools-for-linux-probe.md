# Архивы APK для Linux VM probe

2026-11-25 новый прогон VM остановился до тестов: Alpine v3.24 предлагает
python3 3.14.10-r2, а прежний python3=3.14.10-r1 больше не выбирается из index.
Это не результат namespace/identity regression; report остался failed.

В scripts/linux-probe-packages.lock.json закреплены Python r2 и прежний
bubblewrap 0.12.0-r0: имя архива, версия, repository, размер, SHA-256 и лицензия.
Оба — main/x86_64 официального v3.24 репозитория. SHA вычислены по загруженным
официальным архивам; версии/размеры/лицензии сверены с APKINDEX. Python:
8482165 байт, ef4c4688fa4360e7b544aa723374fb202af25ff662b0b6adef2cd34f03254c7b.
Bubblewrap: 29647 байт, 7755592c3f7c6de79a5c3c13554ada6302dbd98e520fe6dd8064f87ba77092e5.

Host проверяет хеш кеша, передаёт в гостя точные архивы, гость повторяет SHA-256.
Diskless apk отверг прямую установку локальных файлов: они не являются пакетами
репозитория и потерялись бы после reboot. Этот путь оставлен неуспешным, без
force-non-repository. Вместо него host обслуживает оригинальный подписанный
APKINDEX официального main и те же два архива; apk add выбирает пакеты по именам
и точным версиям обычным способом. Остальные имена APK перенаправляются только
на HTTPS того же официального репозитория. Index не переподписывается, новые
ключи доверия не добавляются. Его SHA сохраняется в отчёте. В гостевую папку
исполняемых probes копируются только ELF, без repository metadata.
Проверка подписей встроенными Alpine keys сохраняется; allow-untrusted и обход
TLS/ключей не используются. Парсер lock
не принимает другие имена, пути, платформу, незакреплённую версию или digest.
Хеш lock связан с отчётом и проверяется после выполнения вместе с harness,
crates, test sources и Cargo.lock. Артефакты не содержат реальных данных.

Это закрепляет два инструмента тестовой VM, а не весь transitive APK-граф.
Транзитивные системные зависимости по-прежнему берутся из подписанного v3.24
репозитория. Полная воспроизводимость M6 этим не заявлена; отсутствие архива
или неудачный прогон не заменяются другой версией автоматически.

Источники: [официальный main index](https://dl-cdn.alpinelinux.org/alpine/v3.24/main/x86_64/APKINDEX.tar.gz),
[Python APK](https://dl-cdn.alpinelinux.org/alpine/v3.24/main/x86_64/python3-3.14.10-r2.apk),
[bubblewrap APK](https://dl-cdn.alpinelinux.org/alpine/v3.24/main/x86_64/bubblewrap-0.12.0-r0.apk).
