# 0001. Локальное ядро и последовательное включение возможностей

Статус: принято. Дата: 2026-11-22.

Первый запуск не должен создавать сетевой обход до реализации M2 и укрепления
песочниц. Реализуем M0 на Rust, без импорта Python из учебного примера.
Неизвестные и ещё не реализованные возможности возвращают типизированную ошибку.
Удалённые Tor, Nym, zkAPI не заменяются прямым HTTP и не изображаются работающими.
Локальная модель подключается только через Unix socket к llama.cpp; TCP Ollama
не используется, поскольку SPEC требует локальный IPC без сетевого доступа core.

Для M0 используем предусмотренные SPEC отдельные зашифрованные файлы
XChaCha20-Poly1305. SQLite/SQLCipher добавляется при интеграции долговременной БД
M1; незашифрованного SQLite нет. Ключи предоставляет вызывающая сторона в памяти;
автоматическое хранение ключей без DPAPI/Keychain/Secret Service запрещено.
Пароль + случайный секрет ОС проходят Argon2id. У каждого домена независимый ключ.
Это не заменяет требования M6 к mlock, swap, запрету дампов и crypto-shredding
физических носителей; до их проверки приложение является прототипом.

Прямые зависимости закреплены точными версиями, транзитивные и контрольные суммы —
Cargo.lock/package-lock.json. serde/serde_json: строгие схемы; thiserror: ошибки без
содержимого; secrecy/zeroize: секреты в памяти; chacha20poly1305: AEAD файлов;
argon2: KDF; rand: CSPRNG ключей/nonce и планирование; sha2: одобрение по хешу;
regex/unicode-normalization/base64: детерминированный leakcheck; tokio: локальный
асинхронный IPC; libc: ограничения Linux и права сокетов (только nw-sandbox
содержит изолированные системные вызовы); tempfile: синтетические тесты.
TypeScript используется для расширения и интерфейса; Tauri v2 — оболочка UI.
Новые зависимости для следующих этапов требуют дополнения ADR.

Ссылки: [RustCrypto AEAD](https://docs.rs/chacha20poly1305/0.10.1/),
[Argon2](https://docs.rs/argon2/0.5.3/),
[Tokio Unix sockets](https://docs.rs/tokio/1.48.0/tokio/net/struct.UnixStream.html).

HTTP через локальные сокеты: axum 0.8.9, hyper 1.12.0, hyper-util 0.1.21,
http-body-util 0.1.5, tower 0.5.3. Используется низкоуровневое подключение к уже
открытому UnixStream; TCP-коннектора и DNS-резолвера в клиенте нет. Ограничены
размер тела и время ответа. Tauri 2.12.4 / tauri-build 2.7.6 и CLI 2.12.6 —
десктопная оболочка; TypeScript 7.0.2 — компилятор без runtime-зависимостей UI.
Статический интерфейс собирается без dev-сервера и без HTTP-порта.

cargo-deny обнаружил RUSTSEC-2026-0097 (rand 0.8.5) и RUSTSEC-2026-0386
(tokio 1.48.0). Версии обновлены до 0.8.8 и 1.54.1, исключений в deny нет.

Транзитивные CSS-парсеры Tauri используют MPL-2.0, target-lexicon — Apache-2.0
WITH LLVM-exception. Эти лицензии явно разрешены в deny.toml; уведомления о
лицензиях должны войти в дистрибутив M6. WebView работает incognito, автозаполнение
и проверка правописания полей отключены. Временный профиль ОС всё равно требует
отдельного аудита дисковых записей M6: сейчас только синтетические примеры.
