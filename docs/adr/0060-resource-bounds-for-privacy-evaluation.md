# Ресурсы оценки приватности

Первый Ubuntu pilot 45094291240 завершился ENOSPC до первого случая и не считается
измерением. Две пары debug/release артефактов и исходные части вместе с merged
GGUF заполнили runner. Оценка использует release для worker, client и native CPU
проверки. После merge CI удаляет только части из закреплённого каталога: сначала
проверяет весь итоговый файл и каждый источник, затем unlink; при неверном хеше,
имени, типе или symlink операция отказывает. Регрессия проверяет отсутствие
частичного удаления при плохом втором источнике и сохранение итогового файла.

Хеш merged 7B дополнительно закреплён в scripts/privacy-models.json:
7376371b5fb12633c2d9fd4805c8312538072a59c1929db40c7d95794becab76.
Он совпал при merge на Windows и в Ubuntu run 45094291240. Это воспроизведение
этого GGUF-преобразования; критерий воспроизводимости релизных бинарников M6
остаётся отдельным и открытым.

Случай privacy-v3 имеет до 26 полных общих шаблонов фактов. Буквенный словарь
передаёт все факты и все 64 комбинации без усечения. Исходные случайные nonce
каждого кандидата остаются у атакующего кода; модели передаётся результат их
точного сопоставления с наблюдаемым текстом, чтобы не занимать контекст 128
неинформативными hex-строками. Индекс субъекта не используется. Регрессия
восстанавливает каждую комбинацию фактов и проверяет nonce matches. Отдельный
oracle продолжает проверять канарейки в исходящих байтах, включая кодировки.
Это замкнутый синтетический мир, не доказательство анонимности любого текста.

До held-out заморозки raw-атакующий должен пройти калибровку по каждой паре
язык/приватная группа. Нельзя засчитать умение находить nonce в hard_data как
умение связывать редкие факты на армянском. Неточность, таймаут и отсутствие
полных данных остаются failed/unmeasured, без замены на случайный ответ.
