# ADR 0101: исполняемый паритет M5 с anti.py selftest

Статус: принято. Дата: 2026-11-26.

## Контекст

Rust уже содержит независимые формулы оси и тест с углами из урока. Один похожий
тест не обнаружит расхождения, если изменится эталонный selftest или его score.
SPEC §9 требует совпадения математики с `web3lesson/anti.py selftest`.

## Решение

Добавить отдельный CI job `drift-math-parity`. Test-only Python runner выполняет
настоящий selftest урока, затем передаёт его синтетические векторы Rust example
`math_reference` через stdin. Сравниваются три базовые проекции и все поля Rust
score (позиции, косинусы, шаги, откаты, покрытие и valid) для корректного плана,
отката и неправильного числа этапов. Округлённые результаты сравниваются точно.

Python использует только стандартную библиотеку, запрещает urlopen и направляет
состояние урока во временную папку. Production-код не импортирует урок и не
получает Python-зависимости. Сборка примера ограничена CARGO_BUILD_JOBS=4.

## Последствия

Изменение математики любой стороны требует явного согласования эталона. Тест
не оценивает качество эмбеддингов реальной модели или результат персонализации.
Существующие Rust-тесты некорректных векторов остаются обязательными.
