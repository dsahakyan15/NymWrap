# Воспроизводимая ведомость исходных компонентов CycloneDX

## Решение

scripts/sbom.mjs строит CycloneDX 1.6 из трёх `cargo metadata --locked --offline`
графов для явно заданного target. Корни — поставляемые бинарники core/API/model/
native host/importer, desktop и netd. Обход включает normal/build edges, исключает
dev-only корни и объединяет общие зависимости. Идентичности разных источников не
сливаются. Registry-компонент обязан иметь SHA-256 в соответствующем Cargo.lock;
неизвестный registry/git/source отклоняется. Локальные патчи и UI/расширение
получают детерминированный source-tree digest; symlink traversal запрещён.
Абсолютные пути разработчика, авторы и пользовательские данные не включаются.

source-tree-v1: сортированные относительные UTF-8 пути файлов, NUL, hex SHA-256
содержимого, NUL; общий SHA-256 с доменным префиксом. target/node_modules/.git/
dist исключены. SBOM не содержит времени или случайного id: повтор того же
графа/исходников/target даёт одинаковые байты. UI и расширение — собственный код
без runtime npm-библиотек; их build lock-файлы входят в digest.

Валидация — по официальной
[схеме CycloneDX 1.6](https://github.com/CycloneDX/specification/blob/55343ba19dee1785acf1ce9191540d5fd7b590db/schema/bom-1.6.schema.json),
SPDX и JSF из того же commit, с тремя закреплёнными SHA-256. PowerShell Test-Json
получает замкнутую схему в памяти: внешние ссылки заменены ссылками на те же
встроенные определения, непроверенных загрузок при валидации нет. Новых
runtime-зависимостей или валидатора из npm/pip не добавлено.

## Проверки и границы

Тесты проверяют lock/hash/source errors, отсутствие dev-компонентов/host paths,
граф build edges, изменение digest с кодом и отказ на junction/symlink.
Локально собрана и проверена схема Windows-инвентаря из 639 компонентов,
две генерации дали одинаковые байты. CI создаёт три source SBOM и прикладывает
их как артефакты. Файл явно помечен pre-build: архивные хеши не удостоверяют
состав нативных библиотек, GGUF пользователя или готовых exe. Для закрытия M6
по-прежнему нужны vet, подписи релиза и сравнение бинарников на двух машинах.
