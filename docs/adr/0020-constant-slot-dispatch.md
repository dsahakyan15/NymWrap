# Реальные задания в диспетчере постоянных слотов

## Решение

При явно включённом constant/standard/L3 Route сначала строит ShapedRequest
из последнего проверенного Prepared. В bounded FIFO (64) находятся только
неизменяемое тело, параметры маршрута, epoch, id задания и канал результата.
API-ключ ещё не арендован, бюджет send не потрачен, моделей после очереди нет.
Диспетчер отдаёт реальному заданию очередной сохранённый слот, иначе создаёт
независимую приманку. В Poisson реальные задания сохраняют прежнее поведение.

Сохранение слота предшествует работе. Общий дневной бюджет проверяется до
извлечения FIFO: исчерпание оставляет задание ждать, а не отправляет без cover.
Аренда удостоверения и окончательное резервирование выполняются обычным send.
У приманки те же нормализованные параметры ответа 2048, что у GUI-запроса.
Назначение слота real/decoy — только локальная зашифрованная метаинформация,
провайдеру оно не передаётся.

Отмена получателя, смена epoch и очистка сессии удаляют ожидающие тела. При
отмене уже исполняемого send его future удаляется, а прерванный обмен netd
не переигрывается. Слот не заменяется другим запросом после неопределённой
попытки. После рестарта сохранённые задания требуют нового просмотра.

Синхронный remote API при constant возвращает async_remote_required вместо
отправки вне слота или удержания HTTP до возможного клиентского retry.
GUI использует сохраняемые задания; отдельный async HTTP endpoint следует
тем же правилам. Strict/paranoid L3 по-прежнему запрещён.

## Проверки и границы

Тест с закреплёнными часами проверяет: до слота ничего не отправляется,
исчерпанный бюджет оставляет тело в FIFO, канарейка в теле отсутствует,
следующие сутки освобождают один слот, отсутствующий транспорт даёт закрытый
отказ. Семидневные тесты сохраняемого Scheduler ограничивают оба бюджета.

Постоянный график намерений не гарантирует точный пакетный ритм: bootstrap,
задержка провайдера и отсутствие транспорта могут задержать выход. Предварительная
подготовка приманок добавлена в ADR 0022. Захват пакетов требуется до закрытия M3;
нынешние корзины байтовые. Новых зависимостей нет.
