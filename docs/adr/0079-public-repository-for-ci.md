# Публичный репозиторий для CI

ADR 0049 создал приватный репозиторий. После этого GitHub Actions отклонял
задания до первого шага из-за оплаты аккаунта, и этапы нельзя было закрыть.
Пользователь решил сделать репозиторий публичным: для публичных репозиториев
стандартные runner'ы Windows, Linux и macOS бесплатны. Первый run после
смены видимости (45481719481) запустил все задания.

Перед сменой видимости проверена вся история (32 коммита): авторы — только
`NymWrap <user@localhost>` и `T3 Code`; почты — авторы вендорных пакетов и
синтетические `@example.test`; ключей и токенов сервисов нет; фикстуры
синтетические. Единственный личный фрагмент — имя в примере hostname в SPEC —
заменён на нейтральное в HEAD. В старых коммитах он остаётся; переписывание
истории сочтено несоразмерным.

Следствия:

- workflow не используют секреты и `pull_request_target`; PR из форков
  получают только read-only токен;
- self-hosted runner к публичному репозиторию не подключается: чужой PR
  выполнил бы код на машине пользователя;
- приватный ключ выпуска никогда не попадает в репозиторий и в секреты
  Actions (ADR 0080);
- новые фикстуры по-прежнему только синтетические (AGENTS.md).
