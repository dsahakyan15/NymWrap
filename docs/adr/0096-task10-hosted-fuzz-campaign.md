# Задача 10: суточная кампания на GitHub-hosted runners

Статус: принято, 2026-11-26. Дополняет ADR 0070.

## Контекст

Задача требует 24 часа фаззинга каждого target только в GitHub Actions.
Проверены `fuzz-campaign.yml`, reusable `fuzz-campaign-segment.yml` и
`scripts/fuzz-campaign.mjs` на исходном коммите a120a5f.
[GitHub ограничивает hosted job шестью часами](https://docs.github.com/en/actions/reference/limits).

## Решение

Сохраняем подготовленную цепочку: `audit_import`, `ipc_frames` и
`shield_roundtrip` исполняются параллельно, каждый target проходит шесть
последовательных сегментов по 14 400 секунд. Каждый segment job имеет лимит
300 минут: 240 минут исполнения и 60 минут для подготовки, передачи корпуса
и отчётов. Общая длительность workflow может превышать сутки; лимит отдельного
job этому не мешает. Десятисекундный native preflight не входит в 24 часа.

Workflow и production-код не меняются, новых зависимостей нет. Фаззинг локально не запускаем.

Сборка выполняется один раз на target. Следующий сегмент получает тот же
бинарник, корпус и receipt предыдущего сегмента. Проверяются SHA исходников,
бинарника и корпуса, commit, run ID и attempt. Финальный агрегатор принимает
только все 18 связанных успешных receipts с подтверждёнными wall/engine time.
Частичную попытку, ранний exit 0 и короткий smoke не засчитываем.

## Свидетельства и ограничения

Кампания запускается через workflow_dispatch на main. Run ID, ссылки,
фактический статус и локальные проверки записываются в единственный раздел
«Задача 10 — фаззинг 24 часа» в `docs/IMPLEMENTATION.md`.
До успешного завершения всех сегментов кампания и пункт M6 остаются открытыми.
После завершения требуется сохранить `fuzz24-complete-a<attempt>` вместе
с manifests/receipts до истечения retention (семь дней); промежуточные
корпуса хранятся два дня. Итог означает 24 часа с перезапусками процесса,
`continuous_process=false`, а не один непрерывный процесс.

Входы только синтетические; harness не делает сетевых запросов, model inference
или действий RPC. Операционные логи и артефакты кампании не содержат данных
пользователя. Восемь инвариантов AGENTS.md сохраняются; остальные критерии M6
эта задача не закрывает.
