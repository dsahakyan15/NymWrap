# Закреплённый многоязычный embedding-кандидат

Nomic v1.5 заявлен для English; приёмка EN/RU/HY требует настоящего измерения
многоязычной семантики. Добавлен кандидат из официального
[Qwen GGUF](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B-GGUF/tree/370f27d7550e0def9b39c1f16d3fbaa13aa67728):
Qwen3-Embedding-0.6B-Q8_0.gguf, 639150592 байта, SHA-256
06507c7b42688469c4e7298b0a1e16deff06caf291cf0a5b278c308249c3e439.
Ревизия 370f27d7550e0def9b39c1f16d3fbaa13aa67728, Apache-2.0;
локальный файл проверен по официальному LFS SHA. Приложение его не скачивает.

[Карточка](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B-GGUF/blob/370f27d7550e0def9b39c1f16d3fbaa13aa67728/README.md)
указывает 100+ языков, 1024 координаты, окно 32k и llama.cpp pooling last.
Backend выбирает pooling, общий префикс, размерность и предел только по хешу
проверенного файла. Nomic сохраняет mean/search_document/768/8192; Qwen —
last/без префикса/1024/32768. Для симметричного сравнения досье и истории Qwen
получает одинаковое представление без retrieval-инструкции только с одной стороны.
Неизвестный hash не получает предположений о формате embedding.

Для Qwen размер свежего context определяется полным самым длинным входом с
округлением до 512 в пределах модели; вход не усекается. Дополнительная проверка
сравнивает один текст в партиях с разным longest input/context. Nomic сохраняет
прежнее фиксированное окно 8192, чтобы не менять rotary-параметры. KV очищается между текстами,
токены Rust embedding-буферов zeroize. Это не закрывает аудит native-памяти M6.
Private HTTP принимает нейтральное имя local-embedding, фактическую модель
по-прежнему определяет SHA загруженного файла, а не имя из запроса.

Кандидат не становится default linkcheck. ADR 0069 добавляет явную поддержку
его SHA/recipe для development opt-in. Новый native/private-IPC тест проверяет три темы EN/RU/HY,
размерность, норму и отсутствие переноса предыдущего контекста. Даже его успех
не является калибровкой редких сочетаний или held-out приёмкой. Переключение
default потребует проверки идентичности recipe/cache и нового
полного development-прогона. CI кандидата ещё не выполнен из-за внешнего блокера.
