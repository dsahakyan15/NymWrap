# Оценка Shield/linkcheck, задача 5

Данные и наблюдения синтетические. В этом каталоге нет промптов или сырых
ответов модели; текстовые корпуса лежат в tests/models отдельно.

- `development.json` — 384 завершённых наблюдения, исходные SHA восьми частей,
  реальные ответы и два оценщика. Это отрицательный development-кандидат.
- `freeze.json` — исходная политика top_k=3/max_margin=0.03, модели, recipe,
  удерживаемые executable SHA и хеши исходного протокола до held-out.
- `attempts/held-shard-*.json`, `fragments/initial-*.json` — неизменённые
  свидетельства первого, прерванного инфраструктурного запуска.
- `infrastructure-amendment.json` — точный план только ещё не начатых случаев,
  16 неизвестных позиций после остановки, хеш нового координатора.
- `attempts/continuation-*.json`, `fragments/continuation-*.json` — эксклюзивные
  заявления частей и реальные числовые наблюдения продолжения. Повтор запрещён.
- `publication-spec.json`, `publication-spec-v2.json`, `paired-spec.json` —
  методика публикации до разбора held-out. V2 исправляет только учёт пересечения
  раскрытого запроса с отказом ответа; исходный код V1 сохранён в archive/.
  Статистические функции, защита, модели и пороги не меняются.
- `host-restart.json`, `host-restart-amendment.json`, `archive/host-restart-*`
  сохраняют второе отклонение после reboot: 123 полных наблюдения, ещё 8
  неизвестных позиций без повторов; исполняются только 20 не заявленных частей.
- [REPORT.md](REPORT.md) — итоговый отрицательный результат; `held-out.json` —
  336 полных наблюдений, 24 неизвестных позиции и разрезы обоих оценщиков.
- `paired.json`, [linkcheck.svg](linkcheck.svg), [chart.html](chart.html) —
  сравнение исходного текста и выхода на тех же приватных отправленных случаях.

`RUN_NOTES.md` обязателен для интерпретации: исходный замороженный протокол
исполнения нарушен, неизвестные случаи не удаляются и не считаются безопасными.
Source commit бинарников не аттестован, точные SHA сохранены; результат нельзя
приписывать произвольной текущей сборке или default Nomic.

Для проверки после публикации достаточно unit-тестов scripts/tests и пересчёта
зафиксированных числовых наблюдений. CI не должен повторно запускать уже
просмотренный held-out. Команды freeze/generate/run/continuation защищены
одноразовыми receipts; не удаляйте их ради повторного запуска. Дальнейшее
изменение защиты требует нового development и нового невиденного held-out.

Вычисление завершено 2026-11-25 UTC (2026-11-26 Asia/Yerevan). Модельный
private top-1 — 5/39 против 1/64; один приватный outgoing и две raw-атаки
невалидны и не считаются промахами. Изменений порогов после held-out нет.
Локальные измерения не являются зелёной CI-приёмкой; SPEC не закрывается.
